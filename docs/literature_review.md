# Literature Reviews — Table Reasoning: Knowing What Evidence Is Enough

## Research Questions

- **RQ1:** Can LLMs identify the evidence needed to answer a question, and which question types are difficult?
- **RQ2:** Given a question and a partial table, can a model determine whether the available evidence is sufficient?
- **RQ3:** Can a model identify which parts of a table support its answer, and how does table structure affect this?
